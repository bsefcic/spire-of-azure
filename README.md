# Spire of Azure — Offline Cloud Exam Roguelike PWA

An offline-first 120Hz AMOLED **Roguelike Deckbuilder + Exam Simulator** built for **AWS Solutions Architects** preparing for **Microsoft AZ-900** and **AZ-104**.

## Features
- **Two-Track Ascension**:
  - **AZ-900 Track (3 Acts)**: Cloud Concepts, Core Architecture & Services, Management & Governance
  - **AZ-104 Track (5 Acts)**: Entra Identities & Governance, Storage, Compute & Containers, Virtual Networking, Monitor & Backup
- **Turn-Charge Tactical Deckbuilder**: Answer exam-pure Azure scenarios (Single Choice, Multi-Select, Yes/No Matrix, Sequence Ordering) to generate Turn Energy & Streak Multipliers, with instant post-answer **AWS SAA Equivalent & Gotcha** breakdowns.
- **3 Playable Classes, 30+ Upgradable Cards, Relics, Cloud Incidents & Case Study Bosses**
- **Companion Study Modes**:
  - 60-Second Pre-Act Intel Briefings
  - Searchable AWS ↔ Azure Rosetta Stone Codex & 6 Cheat-Sheet Matrices
  - Weak-Spot FSRS Spaced-Repetition Drill
  - 700/1000 Timed Mock Exam Simulator
- **100% Offline Airplane Mode**: Workbox Service Worker precaching + `IndexedDB` persistence + 1-Tap JSON Save Export/Import.
